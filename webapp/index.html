ℹ️ How to Use WEBLEA

📐 Layer Configuration

Define your pavement structure from top to bottom. Each layer requires thickness (except bottom subgrade), elastic modulus, and Poisson's ratio. The last layer is treated as semi-infinite.

↓ Load Configuration

Add circular tire loads with magnitude (force) and X position. All loads are applied at the surface (z=0) along a line (y=0).

📊 Analysis Modes

    Heatmap: 2D visualization of any response over X-Z plane. Toggle interpolation for smooth display.

    Line Plots: Extract profiles at fixed X (depth) or fixed Z (horizontal) from cached heatmap data. Use the slider to change position instantly.

    Pointwise: Calculate specific response values at individual (x, z) coordinates.

📈 Available Responses & Units

Deflections: Use selected length unit (in or mm)

Strains (ε, γ): Microstrain (με) - dimensionless, same for both unit systems

Stresses (σ, τ): Use selected stress unit (psi or MPa)

💡 Tips

    Run Heatmap first - Line Plots use this cached data

    Layer boundaries are shown as dashed lines

    Response values jump at layer interfaces due to property changes
